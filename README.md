# 🔐 Ethical-Hacking

Welcome to my Ethical hacking journey repository.

This repository documents my practical learning and development in ethical and penetration testing through hands-on assessments on intentionally vulnerable machines.

My work currently focus on two lab environments:

## Projects

### 1. kioptrix.

A practical assessment of a vulnerable linux machine in an isolated VirtualBox lab.

Areas investigated:

-Network discovery and reconnaissance

-Port scanning and service enumeration.

-SSH service identification

-SMB and NetBIOS enumeration.

-SSL/TLS configuration analysis

-Identification of outdated services and insecure protocols.


**Current status:** Reconnaissance and enumeration completed; further vulnerability validation and exploitation are pending.


### 2. DevGuru.


A practical investigation of a vulnerable web application environment.

Areas Investigated:

-Network and service discovery

-Web server investigation

-Git repository metadata exposure.

-Application file and configuration review.

-Adminer interface investigation

-Identification of potential information disclosure risks.

**Current status:** service discovery and web investigation in progress.
